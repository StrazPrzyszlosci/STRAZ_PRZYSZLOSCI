# ExecutionPackSkill registry

Ten katalog opisuje małe, audytowalne umiejętności wykonawcze dla agentów i wolontariuszy Straży Przyszłości.

`ExecutionPackSkill` nie jest autonomicznym prawem do działania w świecie fizycznym. To kontrakt pracy: co wolno przeczytać, co wolno wygenerować, jakie artefakty muszą powstać, kto recenzuje wynik i które bramki bezpieczeństwa blokują dalsze kroki.

## Zasada nadrzędna

Każdy skill musi dać się prześledzić według łańcucha:

```text
goal -> inputs -> run -> artifacts -> checks -> reviewers -> approval -> next handoff
```

Dla działań przy żywności, wodzie, zwierzętach, chemii, wysokim napięciu, grzaniu, pompach, mechanice lub urządzeniach radiowych wymagany jest tryb `suggest-only` aż do osobnego zatwierdzenia człowieka.
